A analogia da carta

O envelope: IP

O IP de destino é o endereço final escrito no envelope. O IP de origem é o remetente, quem iniciou a conversa.

Os IPs normalmente permanecem os mesmos durante o encaminhamento. Exceção comum: o NAT do roteador doméstico troca o IP privado de origem por um IP público.

A caixa de entrega: MAC

Os MACs só valem dentro de cada enlace, como a etiqueta da caixa que leva a carta em um trecho.

A cada salto, o roteador abre a caixa, lê o envelope e cria um novo quadro com novos MACs. O MAC de destino identifica a interface do próximo salto, não a rota inteira.

Quem decide o caminho

Cada roteador olha o IP de destino e consulta a sua tabela de roteamento para descobrir o próximo salto.

Só depois disso ele monta o novo quadro, com o MAC da interface desse próximo salto.
